# Definition of Done

- Escopo e comportamento esperado estão claros.
- A implementação respeita padrões existentes.
- Código crítico foi revisado quanto a falhas e manutenção.
- Testes ou checks proporcionais ao risco foram executados.
- Resultado e limitações foram reportados honestamente.
- Aprendimentos ou decisões candidatos foram propostos para aprovação.
